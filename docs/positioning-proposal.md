# Positioning proposal

A proposal for the operator to apply. Nothing in this file has been applied: no
GitHub setting, topic or listing was changed by the change that wrote it.

## The sentence

Tagline: From feature request to reviewable PR — with an AI engineering
workflow.

Description, identical in `package.json`, the plugin manifests and the README:

> Plan a feature as signed spec contracts, build each in its own git worktree,
> put the result through review and verification gates, and merge through a
> queue into one pull request.

The word "autonomous" is dropped everywhere it described the product. The
README keeps it once, further down, to state a limit (no autonomous deploy or
outbound sends).
